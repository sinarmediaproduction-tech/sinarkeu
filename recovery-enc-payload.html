Pemulihan Transaksi Terkunci (enc_payload)

Alat sekali-pakai untuk mendekripsi transaksi lama yang gagal dibuka karena kunci enkripsi sudah berubah (lihat riwayat perbaikan di js/account.js). Jalankan file ini langsung dari folder aplikasi (buka di browser), lalu hapus setelah selesai dipakai.

⚠️ Alat ini akan membaca dan, kalau kamu tekan tombol tahap 2, menulis ulang data ke tabel transactions di Supabase kamu. Tahap 1 (pindai) sepenuhnya aman dan tidak mengubah apa pun — hasilnya ditampilkan dulu sebelum kamu memutuskan lanjut ke tahap 2. Disarankan membuat backup cloud/manual dulu sebelum menekan tombol tahap 2 (menu Cadangkan Data di aplikasi utama).

⚠️ Penghapusan ini permanen dan tidak bisa dibatalkan. Isi asli baris ini (jumlah, kategori, keterangan) sudah tidak bisa dibaca lagi, tapi ID & tanggalnya akan hilang juga. Pastikan sudah membuat backup cloud/manual dulu kalau ragu.
